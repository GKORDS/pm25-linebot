# 🌫️ ไลน์บอทแจ้งเตือนค่าฝุนละออง PM 2.5

แอปพลิเคชันไลน์บอท (LINE Bot) สำหรับ **รายงานค่าฝุนละออง PM 2.5 และแจ้งเตือนอัตโนมัติเมื่อค่าฝุนเกินมาตรฐาน**
พัฒนาด้วยภาษา **Python + Flask** เชื่อมต่อ **LINE Messaging API** และดึงข้อมูลจากระบบ **Air4Thai** ของกรมควบคุมมลพิษ

> โครงงานรายวิชาการสื่อสารและการนำเสนอ (IS) — พัฒนาตามรายงานเรื่อง
> *“การพัฒนาแอปพลิเคชันไลน์บอทแจ้งเตือนค่าฝุนละออง PM 2.5”*

---

## ✨ ความสามารถ (ตรงตามวัตถุประสงค์ของโครงงาน)

| วัตถุประสงค์ในรายงาน | สิ่งที่บอททำได้ |
|---|---|
| 1) รายงานค่าฝุน PM 2.5 ตามพื้นที่ที่ผู้ใช้เลือก | พิมพ์ **“เช็คฝุน”** หรือเลือกสถานี/ส่งตำแหน่ง 📍 บอทตอบค่าฝุนปัจจุบัน |
| 2) แสดงระดับคุณภาพอากาศและคำแนะนำ | แสดงการ์ดสีตามดัชนี AQI **5 ระดับ** (ฟ้า/เขียว/เหลือง/ส้ม/แดง) พร้อมคำแนะนำการปฏิบัติตน |
| 3) แจ้งเตือนอัตโนมัติเมื่อค่าฝุนเกินมาตรฐาน | เมื่อค่าเกิน **37.5 มคก./ลบ.ม.** ระบบส่ง **Push message** ให้ผู้ที่ลงทะเบียนไว้ |

ความสามารถเสริม (ตามข้อเสนอแนะในบทที่ 5): เลือกสถานีจาก **ตำแหน่งที่ตั้งที่ใกล้ที่สุด**, การ์ดแบบ **Flex Message**, และผู้ใช้ **เปิด/ปิดการแจ้งเตือน** เองได้

## 🚀 เริ่มต้นใช้งาน (รันในเครื่องตัวเอง)

### ขั้นที่ 1 — ติดตั้งไลบรารี
เปิด Terminal/PowerShell ในโฟลเดอร์โปรเจกต์ แล้วสร้างสภาพแวดล้อมเสมือนและติดตั้ง

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # macOS/Linux ใช้:  source .venv/bin/activate
pip install -r requirements.txt
```

### ขั้นที่ 2 — ทดสอบการดึงข้อมูลค่าฝุน (ยังไม่ต้องมี LINE)
```powershell
python selftest.py
```
ถ้าเห็นค่าฝุนของสถานีต่าง ๆ แสดงว่าเชื่อมต่อ Air4Thai ได้แล้ว ✅

### ขั้นที่ 3 — สร้าง LINE Official Account แล้วเปิดใช้ Messaging API
> หมายเหตุ: ปัจจุบัน LINE ไม่ให้สร้างช่อง Messaging API ตรง ๆ ในคอนโซลแล้ว ต้องสร้างผ่าน LINE Official Account ก่อน
1. ที่ <https://developers.line.biz/console/> สร้าง **Provider** (เช่น ชื่อตัวเอง) — ระวังอย่ากด *LINE MINI App* (ใช้ไม่ได้)
2. กด **Create a Messaging API channel** → ในกล่องที่ขึ้นมา กดปุ่ม **Create a LINE Official Account** → กรอกชื่อบัญชี/อีเมล/ภูมิภาค `Thailand` แล้วสร้าง
3. เข้า <https://manager.line.biz> → เลือกบัญชีที่เพิ่งสร้าง → **Settings (ตั้งค่า) → Messaging API** → กด **Enable / ใช้ Messaging API** แล้วเลือก **Provider** ที่สร้างไว้
4. กลับมาที่ LINE Developers Console จะเห็นช่อง Messaging API ใต้ Provider แล้ว
   - แท็บ **Basic settings** → คัดลอก **Channel secret**
   - แท็บ **Messaging API** → ที่ **Channel access token (long-lived)** กด **Issue** แล้วคัดลอกโทเค็น

### ขั้นที่ 4 — ใส่ค่าลงไฟล์ `.env`
คัดลอก `.env.example` เป็น `.env` แล้วเติมค่าจริง 2 บรรทัด:
```
LINE_CHANNEL_ACCESS_TOKEN=โทเค็นที่คัดลอกมา
LINE_CHANNEL_SECRET=ซีเคร็ตที่คัดลอกมา
```

### ขั้นที่ 5 — รันบอท แล้วเปิดทางเข้าด้วย ngrok
หน้าต่างที่ 1:
```powershell
python app.py
```
หน้าต่างที่ 2 (เปิด ngrok ให้ LINE เข้าถึงเครื่องเราได้ — ติดตั้งจาก <https://ngrok.com/download>):
```powershell
ngrok http 5000
```
คัดลอก URL แบบ `https://xxxx.ngrok-free.app` ที่ ngrok แสดง แล้วเติม `/callback` ต่อท้าย:
```
https://xxxx.ngrok-free.app/callback
```

### ขั้นที่ 6 — ตั้งค่า Webhook ใน LINE
1. แท็บ **Messaging API** → **Webhook URL** กด **Edit** แล้ววาง URL จากขั้นที่ 5 → **Update** → **Verify**
2. เปิดสวิตช์ **Use webhook** เป็น **On**
3. ปิด **Auto-reply messages** และ **Greeting messages** (ผ่านปุ่ม Edit ที่ลิงก์ไป LINE Official Account Manager) เพื่อให้บอทตอบเองได้

### ขั้นที่ 7 — ทดลองคุยกับบอท
สแกน QR code (แท็บ Messaging API) เพื่อเพิ่มบอทเป็นเพื่อน แล้วพิมพ์ **“เช็คฝุน”** ได้เลย 🎉

## ☁️ นำขึ้นออนไลน์ฟรีด้วย Render (ทำงาน 24 ชม. ไม่ต้องเปิดคอม)

1. นำโปรเจกต์ขึ้น GitHub (อย่าลืมว่า `.env` จะไม่ถูกอัปขึ้นเพราะอยู่ใน `.gitignore`)
2. ที่ <https://render.com> → **New > Web Service** → เชื่อม repo ของคุณ
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app --workers 1`  *(ใช้ worker เดียว ไม่งั้นตัวตั้งเวลาแจ้งเตือนจะรันซ้ำ)*
   - เลือกแพ็กเกจ **Free**
3. แท็บ **Environment** เพิ่มตัวแปร `LINE_CHANNEL_ACCESS_TOKEN` และ `LINE_CHANNEL_SECRET`
4. เมื่อ deploy เสร็จ จะได้ URL เช่น `https://pm25-linebot.onrender.com` → ตั้ง Webhook URL เป็น URL นั้น + `/callback`

> 💡 มีไฟล์ `render.yaml` ให้แล้ว สามารถใช้เมนู **New > Blueprint** เพื่อตั้งค่าให้อัตโนมัติได้

### ⚠️ ข้อควรรู้: Render แพ็กเกจฟรีจะ “หลับ” เมื่อไม่มีคนเรียก ~15 นาที
ระหว่างหลับ ตัวตั้งเวลาแจ้งเตือนในโปรแกรมจะหยุดทำงาน มี 2 วิธีแก้:

- **วิธีง่าย (แนะนำ):** ใช้บริการฟรีอย่าง [UptimeRobot](https://uptimerobot.com) หรือ [cron-job.org](https://cron-job.org) ตั้งให้เรียกหน้าเว็บ `https://<your-app>.onrender.com/` ทุก 5 นาที เพื่อกันไม่ให้หลับ
- **วิธีเสถียรที่สุด:** ตั้งให้ cron-job.org เรียก `https://<your-app>.onrender.com/check?token=<ค่าลับ>` ทุก 1 ชั่วโมง (ตั้งค่า `CHECK_TOKEN` ใน Environment ก่อน) แล้วปิดตัวตั้งเวลาในตัว (`ALERT_ENABLED=false`) — การตรวจค่าฝุนจะถูกสั่งจากภายนอกแทน

## ⚙️ การปรับแต่ง (ตัวแปรใน `.env`)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | — | โทเค็นจาก LINE (จำเป็น) |
| `LINE_CHANNEL_SECRET` | — | ซีเคร็ตจาก LINE (จำเป็น) |
| `DEFAULT_STATION` | `50t` | รหัสสถานีเริ่มต้น |
| `ALERT_ENABLED` | `true` | เปิดตัวตั้งเวลาแจ้งเตือนในตัวโปรแกรม |
| `CHECK_INTERVAL_MINUTES` | `60` | ตรวจค่าฝุนทุกกี่นาที |
| `ALERT_COOLDOWN_HOURS` | `3` | เว้นระยะกี่ชั่วโมงก่อนเตือนซ้ำ (กันสแปม) |
| `CHECK_TOKEN` | (ว่าง) | รหัสลับสำหรับเรียก `/check` จากภายนอก |

## 🔎 หมายเหตุทางเทคนิค (จุดที่ปรับจากโค้ดตัวอย่างในภาคผนวก)

โค้ดในภาคผนวกของรายงานเป็น *โครงสร้างตัวอย่าง* เวอร์ชันที่รันได้จริงนี้ปรับให้ถูกต้องตาม API ปัจจุบัน:

1. **URL ของ Air4Thai** ต้องลงท้าย `.php` → `http://air4thai.pcd.go.th/services/getNewAQI_JSON.php` และใช้ `http` (เว็บใบรับรอง `https` หมดอายุ)
2. **ค่าจาก Air4Thai เป็นสตริงทั้งหมด** และค่าที่ไม่มีข้อมูลคือ `"-1"` โค้ดจึงแปลงเป็นตัวเลขและกรองค่าที่ไม่มีข้อมูลให้แล้ว
3. **การ import ของ line-bot-sdk v3** ที่ถูกต้องคือ `from linebot.v3 import WebhookHandler` (ไม่ใช่ `linebot.v3.webhook`)
4. เพิ่มการเก็บผู้ใช้ลงไฟล์ (กันข้อมูลหายเมื่อรีสตาร์ต), ระบบกันเตือนซ้ำถี่ ๆ, การ์ด Flex และการเลือกสถานีจากตำแหน่ง

ข้อมูลดัชนีคุณภาพอากาศ 5 ระดับและค่ามาตรฐาน 37.5 มคก./ลบ.ม. อ้างอิงตามประกาศกรมควบคุมมลพิษ (พ.ศ. 2566) ตามตารางที่ 2.1 ในรายงาน

## 🛠️ การแก้ปัญหาเบื้องต้น

- **กด Verify ใน LINE แล้วไม่ผ่าน** → ตรวจว่ารันโปรแกรมอยู่, ngrok ยังเปิด, และ URL ลงท้าย `/callback`
- **บอทไม่ตอบ** → ตรวจว่าปิด Auto-reply แล้ว และเปิด Use webhook, ค่าโทเค็น/ซีเคร็ตถูกต้อง
- **selftest ดึงข้อมูลไม่ได้** → ลองใหม่ภายหลัง (Air4Thai อาจปรับปรุงระบบชั่วคราว) หรือเช็คอินเทอร์เน็ต
- **ngrok URL เปลี่ยนทุกครั้งที่เปิดใหม่** → ต้องอัปเดต Webhook URL ใน LINE ใหม่ทุกครั้ง (จึงควรขึ้น Render เมื่อใช้งานจริง)
